| Sourcewala | "The sourcing guy" | Friendly, clear | Generic, many "-wala" brands |

| Mandi AI | Market | Familiar word | Associated with agri markets |
| Procura | Procurement | Works globally | Says nothing to a café owner |

## How to rename the GitHub repo

1. Open the repo on GitHub, go to **Settings > General**.
2. Change **Repository name** from `-` to `bhavtaav`, click **Rename**.
3. GitHub redirects the old URL automatically. Locally, update the remote:

```bash
git remote set-url origin https://github.com/Sumitkumar005/bhavtaav.git
```
