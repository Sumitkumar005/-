# BhavTaav (working name)

**An AI sourcing agent for small Indian buyers.** You tell it what you need. It finds wholesalers, calls them for quotes, checks them out, compares the quotes on the same basis, pushes back on price, and gives you the best 2 or 3 to talk to.

> *Bhav-taav* is Hindi for haggling over price. That is the job this product does for the buyer.
